# Wuff & Wild – Dobermann-Website

Eine responsive, deutschsprachige Website mit Informationen über Dobermänner, ihren Alltag, Training, Pflege und Verantwortung.

## Lokal ansehen

Öffne `index.html` in einem aktuellen Browser. Die Fotos werden von externen Bilddiensten geladen und benötigen eine Internetverbindung. Falls ein Bildlink nicht verfügbar ist, zeigt die Galerie einen Fallback.

## Anpassen

Die Gestaltung und Inhalte befinden sich direkt in `index.html` (CSS und HTML). Externe Bild-URLs können dort im `<img src="...">` geändert werden.
